About This Project

This page demonstrates how to quickly assemble new information pages using the Icoemi CMS library. You can use standard declarative HTML elements such as <ic-tabs>, <ic-card-grid>, and <ic-details>.

All components adapt responsively to both desktop and mobile viewports, adhering to Confoederatio's design aesthetics and standard typography.

Core Features

  • Fully responsive layout with mobile touch navigation.
  • Modular components loaded via Icoemi component engine.
  • Interactive sliding tab navigation.
  • Dark-mode glassmorphic cards and metadata sidebars.
